1 Anatomie & Definition des Binärbaums

Bisher haben wir lineare Datenstrukturen (Stack, Queue, List) betrachtet, bei denen jedes Element genau einen direkten Nachfolger hat. Ein binärer Baum verallgemeinert dies auf eine verzweigte, hierarchische Struktur.

MERKE
Formale Definition: Ein binärer Baum $T$ ist entweder:
1. leer ($T = \emptyset$ bzw. isEmpty() == true), oder
2. er besteht aus einem ausgezeichneten Knoten, der Wurzel ($root$), sowie zwei disjunkten Teilbäumen: dem linken Teilbaum $T_L$ und dem rechten Teilbaum $T_R$, die ihrerseits wieder binäre Bäume sind.

Kernbegriffe:
• Blatt: Ein Knoten ohne Teilbäume (weder links noch rechts).
• Innerer Knoten: Ein Knoten mit mindestens einem nicht-leeren Teilbaum.
• Tiefe eines Knotens: Anzahl der Kanten von der Wurzel bis zu diesem Knoten.
• Höhe des Baumes: Maximale Tiefe aller Knoten ($1 + \max(h_L, h_R)$).

Wurzel (Root)

Der oberste Einstiegsknoten. Besitzt als einziger Knoten des Baumes keinen Vorgänger.

Teilbäume (Subtrees)

Jeder Kindknoten ist selbst die Wurzel eines vollständigen, eigenständigen Binärbaums.

Blätter (Leaves)

Endpunkte der Rekursion. Knoten, bei denen sowohl der linke als auch der rechte Teilbaum leer sind.

Höhe (Height)

Länge des längsten Pfades von der Wurzel zu einem Blatt. Bestimmt die Laufzeit von Suchoperationen.

3 Das binäre Suchbaumkriterium (Binary Search Tree)

Ein binärer Baum wird zu einem binären Suchbaum, wenn für jeden Knoten folgende Ordnungsbedingung erfüllt ist:

Das Suchbaumkriterium:

Für jeden Knoten mit Schlüssel $w$ gilt:
• Alle Knoten im linken Teilbaum haben Schlüssel $< w$.
• Alle Knoten im rechten Teilbaum haben Schlüssel $> w$ (oder $\ge w$).

MERKE
Warum Inorder-Traversierung so mächtig ist:
Wendet man die Inorder-Traversierung (L - W - R) auf einen binären Suchbaum an, so werden die Schlüssel streng monoton wachsend sortiert ausgegeben!
Grund: Man besucht per Definition alle kleineren Werte (links), dann den aktuellen Wert (Wurzel), dann alle größeren Werte (rechts).

1 Aufgabe 1: Anzahl aller Knoten im Baum zählen

Entwickle public int anzahlKnoten(). Ein leerer Baum hat 0 Knoten. Ein nicht-leerer Baum hat 1 Knoten (die eigene Wurzel) plus die Summe der Knoten in beiden Teilbäumen.

Tipp: Prüfe vor dem rekursiven Aufruf, ob this.links != null bzw. this.rechts != null gilt.

Musterlösung
public int anzahlKnoten() {
    if (this.isEmpty()) return 0;
    
    int k = 1; // Eigene Wurzel zaehlen
    if (this.links != null) {
        k += this.links.anzahlKnoten();
    }
    if (this.rechts != null) {
        k += this.rechts.anzahlKnoten();
    }
    return k;
}
2 Aufgabe 2: Baumhöhe (Tiefe) ermitteln

Die Höhe eines Baumes ist definiert als $1 + \max(h_L, h_R)$. Ein leerer Baum besitzt die Höhe 0.

Hinweis: Math.max(a, b) liefert das Maximum zweier Zahlen.

Musterlösung
public int baumHoehe() {
    if (this.isEmpty()) return 0;
    
    int hLinks = (this.links != null) ? this.links.baumHoehe() : 0;
    int hRechts = (this.rechts != null) ? this.rechts.baumHoehe() : 0;
    
    return 1 + Math.max(hLinks, hRechts);
}
3 Aufgabe 3: Anzahl der Blätter zählen

Ein Blatt ist ein Knoten, der weder einen linken noch einen rechten Teilbaum besitzt (links == null && rechts == null). Entwickle public int anzahlBlaetter().

Musterlösung
public int anzahlBlaetter() {
    if (this.isEmpty()) return 0;
    
    // 1. Basisfall: Knoten ist selbst ein Blatt
    if (this.links == null && this.rechts == null) {
        return 1;
    }
    
    // 2. Schritt: Summe der Blaetter beider Teilbaeume
    int bl = 0;
    if (this.links != null) bl += this.links.anzahlBlaetter();
    if (this.rechts != null) bl += this.rechts.anzahlBlaetter();
    return bl;
}
4 Aufgabe 4: Summe aller Knotenwerte berechnen

Entwickle public int summe(), die den eigenen Wert wurzel mit den Summen des linken und des rechten Teilbaums addiert.

Musterlösung
public int summe() {
    if (this.isEmpty()) return 0;
    
    int s = this.wurzel;
    if (this.links != null) s += this.links.summe();
    if (this.rechts != null) s += this.rechts.summe();
    return s;
}
5 Aufgabe 5: Gezielte Suche im binären Suchbaum

Nutze die Suchbaumeigenschaft: Wenn der gesuchte Wert kleiner als die Wurzel ist, muss nur links gesucht werden. Ist er größer, nur rechts. Aufwand: $O(\log n)$.

Musterlösung
public boolean suchen(int s) {
    if (this.isEmpty()) return false;
    if (this.wurzel == s) return true;
    
    if (s < this.wurzel) {
        return (this.links != null) && this.links.suchen(s);
    } else {
        return (this.rechts != null) && this.rechts.suchen(s);
    }
}
