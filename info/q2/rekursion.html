1 Das Grundprinzip der Rekursion

In der Informatik bezeichnet Rekursion ein Lösungsverfahren, bei dem sich eine Methode selbst aufruft, um ein komplexes Problem auf ein kleineres, strukturell identisches Teilproblem zurückzuführen.

1. Säule

Der Rekursionsanker (Basisfall)

Die zwingende Abbruchbedingung. Sie löst den kleinsten, trivialen Fall ohne weiteren Selbstaufruf direkt auf.

Typischer Fehler: Fehlt der Anker oder ist er unerreichbar, ruft sich die Methode unendlich oft auf $\rightarrow$ StackOverflowError.

2. Säule

Der Rekursionsschritt

Verkleinert das Problem echt in Richtung des Ankers und ruft sich selbst mit dem reduzierten Parameter auf. Das Teilergebnis wird verarbeitet.

Formel: Lösung des Gesamtproblems = Eigene Operation + Selbstaufruf(kleineres Problem).

MERKE
Die zwei goldenen Prüffragen für jeden rekursiven Algorithmus:
1. Gibt es einen Basisfall, der garantiert ohne Selbstaufruf terminiert?
2. Wird bei jedem Rekursionsschritt das Argument so verändert, dass es dem Basisfall unweigerlich näher kommt?

Klassisches Lehrbuch-Beispiel: Die Fakultät

Mathematische Definition: $0! = 1$ und $n! = n \cdot (n - 1)!$ für $n > 0$.

public long fakultaet(int n) {
    // 1. Rekursionsanker: Basisfall direkt beantworten
    if (n <= 1) {
        return 1;
    }
    
    // 2. Rekursionsschritt: Verkleinerung (n - 1) und Verknüpfung (n * ...)
    return n * fakultaet(n - 1);
}
2 Der Call-Stack der JVM: Die Brücke zum ADT Stack

Warum haben wir vor der Rekursion den ADT Stack wiederholt? Weil die Java Virtual Machine (JVM) im Hintergrund genau so arbeitet!

Jedes Mal, wenn eine Methode aufgerufen wird, legt die JVM einen neuen Stack-Frame (Speicherbereich mit Parametern und Rücksprungadresse) oben auf den Methodenaufrufstapel (LIFO: Last In – First Out).

Interaktive Ablaufverfolgung: Call-Stack bei fakultaet(3)
JVM Call-Stack (wächst nach oben)
Startzustand
Klicke auf „Nächster Schritt“, um den ersten Methodenaufruf auf den Stapel zu legen.
Aktueller Rückgabewert: noch nicht berechnet
ERKENNTNIS
Hinweg (Expansion): Die Aufrufe stapeln sich, solange der Anker nicht erreicht ist. Jeder Aufruf muss pausieren und warten.
Rückweg (Unwinding): Erst wenn der Basisfall einen konkreten Wert liefert, rechnet die JVM von oben nach unten zurück und leert den Stapel.
3 Ablaufanalyse mit der Trace-Tabelle

In Klausuren und Abiturprüfungen ist die Trace-Tabelle das Standardwerkzeug, um rekursive Algorithmen per Hand präzise nachzuvollziehen.

Aufrufebene Aufruf Parameter n Anker erfüllt? Wartet auf Rückgabewert
1 (Initial) fakultaet(3) 3 Nein (3 > 1) 3 * fakultaet(2) 3 * 2 = 6
2 fakultaet(2) 2 Nein (2 > 1) 2 * fakultaet(1) 2 * 1 = 2
3 (Anker) fakultaet(1) 1 Ja (1 <= 1) kein weiterer Aufruf 1 (direkt)

Lese-Richtung bei der Berechnung: Zuerst von oben nach unten (Spalten 1 bis 5 ausfüllen), am Anker umkehren und die Rückgabewerte von unten nach oben hochreichen!

1 Aufgabe 1: Quersumme einer Zahl berechnen

Die Quersumme ist die Summe aller Ziffern einer Zahl. Entwickle die Methode public int quersumme(int n) rein rekursiv.

Beispiel: quersumme(1234) $\rightarrow 4 + 3 + 2 + 1 = 10$.

Tipp: Die letzte Ziffer liefert n % 10. Die Zahl ohne die letzte Ziffer liefert n / 10.

Musterlösung
public int quersumme(int n) {
    // 1. Anker: Einstellige Zahl liefert sich selbst
    if (n < 10) {
        return n;
    }
    // 2. Schritt: Letzte Ziffer + Quersumme der restlichen Ziffern
    return (n % 10) + quersumme(n / 10);
}
2 Aufgabe 2: Anzahl der Ziffern zählen

Entwickle die Methode public int anzahlZiffern(int n), die rekursiv ermittelt, wie viele Stellen eine positive Zahl hat.

Beispiel: anzahlZiffern(7) = 1, anzahlZiffern(4096) = 4.

Musterlösung
public int anzahlZiffern(int n) {
    // 1. Anker: Wenn n einteilig ist (< 10), hat es genau 1 Ziffer
    if (n < 10) {
        return 1;
    }
    // 2. Schritt: 1 gezählte Stelle + Ziffern des verbleibenden Teils
    return 1 + anzahlZiffern(n / 10);
}
3 Aufgabe 3: String rekursiv spiegeln (umkehren)

Entwickle die Methode public String spiegeln(String s), die eine Zeichenkette umdreht.

Beispiel: spiegeln("INFORMATIK") $\rightarrow$ "KITAMROFNI".

Tipp: Erstes Zeichen: s.charAt(0). Rest-String ab Index 1: s.substring(1).

Musterlösung
public String spiegeln(String s) {
    // 1. Anker: Leerer String oder 1 Buchstabe ist bereits gespiegelt
    if (s == null || s.length() <= 1) {
        return s;
    }
    // 2. Schritt: Rest spiegeln + erstes Zeichen hinten anfügen
    return spiegeln(s.substring(1)) + s.charAt(0);
}
4 Aufgabe 4: Palindromprüfung

Ein Palindrom liest sich vorwärts und rückwärts gleich. Entwickle public boolean istPalindrom(String s).

Beispiel: istPalindrom("OTTO") $\rightarrow$ true, istPalindrom("INFORMATIK") $\rightarrow$ false.

Musterlösung
public boolean istPalindrom(String s) {
    if (s == null) return false;
    String w = s.toUpperCase();
    
    // 1. Anker: Länge 0 oder 1 ist stets ein Palindrom
    if (w.length() <= 1) {
        return true;
    }
    // Prüfe Außenbuchstaben
    if (w.charAt(0) != w.charAt(w.length() - 1)) {
        return false;
    }
    // 2. Schritt: Inneren Teilstring weiterprüfen
    return istPalindrom(w.substring(1, w.length() - 1));
}
5 Aufgabe 5: Verzweigte Rekursion (Fibonacci-Zahlen)

Im Gegensatz zur linearen Rekursion ruft sich die Methode hier zweimal selbst auf. Es entsteht ein Aufrufbaum.

Mathematische Definition: $fib(0)=0$, $fib(1)=1$ und $fib(n) = fib(n-1) + fib(n-2)$.

Musterlösung
public int fibonacci(int n) {
    // 1. Anker: Zwei Basisfälle
    if (n <= 0) return 0;
    if (n == 1) return 1;
    
    // 2. Schritt: Verzweigter Doppelaufruf
    return fibonacci(n - 1) + fibonacci(n - 2);
}
