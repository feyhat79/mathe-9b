🏥 Das Praxis-Szenario: Die Notaufnahme im Klinikum

In einer Notaufnahme treffen zwei völlig unterschiedliche Arten von Patienten ein:
1. Reguläre Patienten (Wartezimmer): Wer zuerst kommt, wird zuerst aufgerufen. Das entspricht exakt einer Queue (Warteschlange - FIFO).
2. Akute Notfälle (Rettungswagen): Notfälle können nicht warten. Der neueste, kritischste Notfall muss sofort behandelt werden. Das entspricht einem Stack (Stapel - LIFO).

🧠 Stufe 0: Das Java-Gedächtnis auffrischen

Vier fundamentale Konzepte, die im Abitur und bei der Klausurbearbeitung blind sitzen müssen:

1. Konstruktor & new

Der Konstruktor heißt exakt wie die Klasse (z. B. public Patient(...)). Er erzeugt mit new ein echtes Objekt aus dem Bauplan und initialisiert die Attribute. Er besitzt niemals einen Rückgabetyp (auch kein void).

2. void vs. Rückgabewert

• void tuEtwas(): Führt eine Aktion aus (z. B. drucken(), enqueue()) und liefert keine Antwort.
• int gibWert(): Liefert eine Antwort und muss mit return ...; enden (z. B. isEmpty()).

3. Der Punktoperator .

Mit dem Punkt befehlen wir einem konkreten Objekt etwas:
patient.drucken(); ➔ „Hey Patient, drucke deine Daten!“
wartezimmer.dequeue(); ➔ „Wartezimmer, entferne den vordersten Patienten!“

4. Type-Casting (Patient)

Weil die Methoden front() und peek() allgemein den Typ Object liefern, müssen wir Java in runden Klammern mitteilen, was wirklich darin steckt:
Patient p = (Patient) wartezimmer.front();

📌 Stufe 2: Methoden-Spickzettel (Queue vs. Stack)

Queue (Warteschlange) FIFO-Prinzip

First In, First Out: Wer zuerst kommt, wird zuerst bedient (z. B. Wartezimmer, Drucker-Warteschlange).

MethodeWirkung & Erklärung
enqueue(Object o)Fügt o hinten an die Schlange an.
dequeue()Entfernt das vorderste Objekt.
front(): ObjectLiefert das vorderste Objekt (ohne es zu löschen).
isEmpty(): booleanGibt true zurück, falls die Schlange leer ist.
Stack (Stapel) LIFO-Prinzip

Last In, First Out: Das zuletzt abgelegte Element liegt oben (z. B. Notfallstapel, Rückgängig-Funktion).

MethodeWirkung & Erklärung
push(Object o)Legt o oben auf den Stapel.
pop()Entfernt das oberste Objekt.
peek(): ObjectLiefert das oberste Objekt (ohne es zu löschen).
isEmpty(): booleanGibt true zurück, falls der Stapel leer ist.
Aufgabe 1: Trockenübung (Trace-Tabelle & Aufrufreihenfolge) Verständnis

Folgende Aktionen finden nacheinander in der Notaufnahme statt:

Schritt 1: Patient Anna (A) und Patient Bernd (B) betreten das Wartezimmer (Queue).
Schritt 2: Rettungswagen liefert Notfall Xaver (X) ein (Stack).
Schritt 3: Patientin Clara (C) betritt das Wartezimmer (Queue).
Schritt 4: Rettungswagen liefert Notfall Yvonne (Y) ein (Stack).

Frage: In welcher Reihenfolge werden die Patienten behandelt, wenn das Ärzteteam nacheinander zuerst 2 Notfälle und direkt danach 2 normale Patienten behandelt?

💡 Musterlösung & Schritt-für-Schritt-Erklärung anzeigen ▼

1. Zustand der beiden Datenstrukturen vor der Behandlung:

  • Queue (Wartezimmer): [Vorne] Anna ➔ Bernd ➔ Clara [Hinten]
  • Stack (Notfallstapel): [Oben] Yvonne ➔ Xaver [Unten]

2. Reihenfolge der Behandlung:

  1. 1. Yvonne (LIFO: Yvonne kam zuletzt auf den Notfallstapel und liegt ganz oben!)
  2. 2. Xaver (LIFO: Nach dem Entfernen von Yvonne liegt Xaver oben auf dem Notfallstapel)
  3. 3. Anna (FIFO: Anna betrat als Erste das Wartezimmer und steht ganz vorne)
  4. 4. Bernd (FIFO: Bernd saß hinter Anna und rückt an die erste Position)

Hinweis: Clara bleibt vorerst im Wartezimmer sitzen, da nur zwei reguläre Patienten aufgerufen wurden.

Aufgabe 2: Warteschlange abarbeiten (Queue - FIFO) Programmierung

Öffne in BlueJ den Quelltext der Klasse Notaufnahme. Implementiere die Methode naechstenNormalenPatientenBehandeln() anhand der folgenden 4 Schritte:

  1. Prüfen: Sitzt überhaupt jemand im Wartezimmer? (Nutze !wartezimmer.isEmpty()).
  2. Holen & Casten: Hole den vordersten Patienten mit front(), caste ihn auf (Patient) und rufe p.drucken() auf.
  3. Entfernen: Nimm den Patienten mit wartezimmer.dequeue() aus dem Wartezimmer heraus.
  4. Else-Zweig: Falls das Wartezimmer leer war, gib eine Meldung auf der Konsole aus.
public void naechstenNormalenPatientenBehandeln() {
    // 1. Prüfe, ob das Wartezimmer NICHT leer ist:
    if (!wartezimmer.isEmpty()) {
        // 2. Vordersten Patienten holen, casten und drucken() aufrufen:
        Patient p = (Patient) wartezimmer.front();
        ...
        // 3. Patienten aus dem Wartezimmer entlassen (vorne entfernen):
        wartezimmer.dequeue();
    } else {
        // 4. Meldung ausgeben, dass niemand wartet:
        System.out.println("Das Wartezimmer ist leer!");
    }
}

Aufgabe 3: Notfallstapel programmieren (Stack - LIFO) Programmierung

Programmiere nun die beiden Notfall-Methoden in Notaufnahme.java:

  1. notfallEinliefern(name, alter, beschwerde, schmerzlevel):
    Erzeuge mit new Patient(...) ein neues Patientenobjekt und lege es mit notfallStapel.push(p) oben auf den Notfallstapel.
  2. naechstenNotfallBehandeln():
    Prüfe mit !notfallStapel.isEmpty(). Falls ein Notfall da ist: mit peek() ansehen, auf (Patient) casten, drucken() aufrufen und mit pop() oben vom Stapel entfernen.
💡 Musterlösung für Aufgabe 3 anzeigen ▼ 
public void notfallEinliefern(String pName, int pAlter,
                              String pBeschwerde, int pSchmerzlevel)
{
    Patient p = new Patient(pName, pAlter, pBeschwerde, pSchmerzlevel);
    notfallStapel.push(p);
    System.out.println("🚨 NOTFALL EINGELIEFERT: " + pName 
                       + " (Schmerzlevel " + pSchmerzlevel + ")");
}

public void naechstenNotfallBehandeln()
{
    if (!notfallStapel.isEmpty())
    {
        Patient p = (Patient) notfallStapel.peek();
        System.out.print("🚨 [BEHANDLUNG NOTFALL] ");
        p.drucken();
        notfallStapel.pop();
    }
    else
    {
        System.out.println("Keine akuten Notfälle vorhanden.");
    }
}

⭐ Stufe 4: Algorithmen-Challenge (Abitur-Muster)

Aufgabe 4: Traversieren & Zählen mit Hilfs-Queue Abitur-Muster

Das Problem: Wir wollen alle Patienten im Wartezimmer auflisten (oder zählen), ohne dass das Wartezimmer danach leer ist! Weil eine Queue keinen Index-Zugriff (wie ein Array) erlaubt, müssen wir die Elemente über eine Hilfs-Queue umschaufeln.

Der 2-Schritte-Algorithmus:
  1. Erzeuge eine temporäre Hilfs-Queue: Queue hilfsQueue = new Queue();
  2. Schleife 1: Solange das Original nicht leer ist: vorderstes Element holen, verarbeiten (ausgeben/zählen), in hilfsQueue.enqueue(...) sichern und aus der Original-Queue per dequeue() entfernen.
  3. Schleife 2: Alle Elemente von hilfsQueue wieder zurück in die Original-Queue schaufeln!

Arbeitsauftrag: Implementiere die Methoden wartezimmerAusgeben() und anzahlWartende(): int.

💡 Musterlösung für Aufgabe 4 (Ausgeben & Zählen) anzeigen ▼

1. Quelltext für wartezimmerAusgeben():

public void wartezimmerAusgeben()
{
    Queue hilfsQueue = new Queue();
    System.out.println("=== PATIENTEN IM WARTEZIMMER ===");

    // 1. Ausgeben und auf Hilfs-Queue sichern
    while (!wartezimmer.isEmpty())
    {
        Patient p = (Patient) wartezimmer.front();
        p.drucken();
        hilfsQueue.enqueue(p);
        wartezimmer.dequeue();
    }

    // 2. Zurück in die Original-Queue schaufeln
    while (!hilfsQueue.isEmpty())
    {
        wartezimmer.enqueue(hilfsQueue.front());
        hilfsQueue.dequeue();
    }
    System.out.println("================================");
}

2. Quelltext für anzahlWartende(): int:

public int anzahlWartende()
{
    Queue hilfsQueue = new Queue();
    int anzahl = 0;

    // 1. Durchzählen und umschaufeln
    while (!wartezimmer.isEmpty())
    {
        anzahl++;
        hilfsQueue.enqueue(wartezimmer.front());
        wartezimmer.dequeue();
    }

    // 2. Zurück in die Original-Queue schaufeln
    while (!hilfsQueue.isEmpty())
    {
        wartezimmer.enqueue(hilfsQueue.front());
        hilfsQueue.dequeue();
    }

    return anzahl;
}
Aufgabe 5 (Zusatz): Triage-Prioritätssteuerung Experte

In der Notfallmedizin gilt: Akute Notfälle haben immer absolute Priorität vor dem normalen Wartezimmer!

Implementiere die Methode triageBehandlung():
• Falls mindestens ein Notfall auf dem notfallStapel liegt ➔ Behandle den nächsten Notfall.
• Sonst, falls Patienten im wartezimmer sitzen ➔ Behandle den nächsten normalen Patienten.
• Falls beide Datenstrukturen leer sind ➔ Kurze Entwarnungs-Meldung auf der Konsole ausgeben.

💡 Musterlösung für Aufgabe 5 (Triage-Steuerung) anzeigen ▼ 
public void triageBehandlung()
{
    if (!notfallStapel.isEmpty())
    {
        naechstenNotfallBehandeln();
    }
    else if (!wartezimmer.isEmpty())
    {
        naechstenNormalenPatientenBehandeln();
    }
    else
    {
        System.out.println("Weder Notfälle noch normale Patienten vorhanden. Ruhe im Klinikum!");
    }
}
