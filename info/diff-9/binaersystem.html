➗ Der Divisionsalgorithmus (: 2 mit Rest)

Wie wandelt man eine Zahl wie 25 oder 42 systematisch in Binär um, ohne raten zu müssen? Ganz einfach: Wir teilen fortlaufend durch 2 mit Rest, bis 0 herauskommt.

⚠️ Die goldene Regel:
Die Reste werden von UNTEN nach OBEN gelesen! Der erste Rest ist das kleinste Bit (Einerstelle, LSB). Der letzte Rest ist das höchstwertige Bit (MSB).

➕ Schriftliche Binäraddition

Computer rechnen genauso wie in der Grundschule von rechts nach links. Es gibt nur 4 Grundregeln:

0 + 0 = 0
Summe 0, kein Übertrag
0 + 1 = 1
Summe 1, kein Übertrag
1 + 0 = 1
Summe 1, kein Übertrag
1 + 1 = 10₂
0 schreiben, 1 gemerkt!
⭐ Der Spezialfall bei 3 Einsen (wenn schon ein Übertrag vorliegt):
1 + 1 + 1 = 11₂ $\rightarrow$ 1 schreiben, 1 gemerkt (Übertrag)!

Musterbeispiel: Schriftliche Addition mit Übertragszeile (Ü)

1 0 1 1₂ (11 dezimal) + 0 1 1 0₂ ( 6 dezimal) Ü: 1 1 1 (Überträge nach links weitergeben) ------------------ 1 0 0 0 1₂ (17 dezimal) -> Probe: 16 + 1 = 17 ✓

🔌 Der Ausblick: Die Brücke zur Hardware

Wenn wir zwei Bits ($A$ und $B$) auf einem Steckbrett mit Strom addieren möchten, stellen wir fest: Ein einzelnes Lämpchen reicht nicht! Denn bei $1+1$ entsteht die zweistellige Zahl $10_2$.

Jede Addierer-Schaltung benötigt deshalb immer ZWEI Ausgänge:

  • Summen-Ausgang ($S$): Zeigt das Ergebnis der aktuellen Stelle an ($0$ oder $1$).
  • Übertrags-Ausgang ($C$, Carry): Reicht eine $1$ an die nächste Stelle weiter!
