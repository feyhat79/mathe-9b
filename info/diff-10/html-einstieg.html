Einstieg in HTML: Wie aus Text eine Website wird

Jede Website im Internet – vom Schulportal bis zum Online-Shop – basiert auf derselben Grundsprache: HTML. In dieser Lerneinheit erarbeiten wir das Fundament von Grund auf: Warum reicht normaler Text für den Browser nicht aus? Wie ist ein HTML-Dokument aufgebaut? Und wie erstellst du im Browser sofort deine erste eigene Webseite?

Fahrplan der Reihe Erst selbst verstehen, dann im 2er-Team entwickeln

In den ersten Stunden lernst du HTML (und später CSS) Schritt für Schritt ohne KI-Hilfe, damit du Quellcode sicher lesen, schreiben und Fehler selbst erkennen kannst. Am Ende der Reihe ersetzt ein eigenes Website-Projekt im 2er-Team die Klassenarbeit – dort darfst du auch gezielt die Schul-KI (AIS) als Werkzeug einsetzen.

1 Ausgangslage: Warum braucht der Browser überhaupt HTML?

Stell dir vor, du schreibst einen kurzen Steckbrief in einer einfachen Textdatei: Eine große Überschrift, darunter zwei Absätze und ein wichtiges Wort fett gedruckt. Für uns Menschen ist sofort klar, was eine Überschrift und was ein Absatz ist. Für den Webbrowser (z. B. Safari, Chrome oder Edge) ist reiner Text jedoch völlig unstrukturiert.

• So soll es auf der Website aussehen
<h1>Willkommen in Diff-10</h1>

<p>In diesem Kurs entwickeln wir eigene Websites.</p>

<p>Wichtig: <strong>Sorgfalt</strong> schlägt Tempo.</p>

• Was der Browser ohne HTML macht
Willkommen in Diff-10 In diesem Kurs entwickeln wir eigene Websites. Wichtig: Sorgfalt schlägt Tempo.
  • Alle Zeilenumbrüche (Enter) im Quelltext werden zu einem einzigen Leerzeichen zusammengefasst.
  • Mehrfache Leerzeichen werden einfach verschluckt.
  • Der Browser weiß nicht, was eine Überschrift, ein Absatz oder ein Link sein soll.

Die Lösung heißt HTML (Hypertext Markup Language). HTML ist keine Programmiersprache wie Python oder Java (es gibt keine Schleifen oder Berechnungen), sondern eine Auszeichnungssprache (Markup Language): Sie markiert Textteile mit sogenannten Tags in spitzen Klammern (<...>), damit der Browser ihre Bedeutung und Struktur erkennt.

2 Bauplan: Anatomie eines Elements & das HTML-Grundgerüst

Fast jedes HTML-Element funktioniert wie eine Klammer um den Inhalt: Es sagt dem Browser genau, wo eine Rolle beginnt und wo sie wieder endet.

Aufbau eines HTML-Elements (Beispiel: Hauptüberschrift)
<h1>
Öffnendes Tag (Start)
Meine Website
Inhalt (Content)
</h1>
Schließendes Tag (mit /)

Ausnahme (Leere Tags): Elemente ohne eigenen Textinhalt – wie ein Zeilenumbruch <br> oder eine Trennlinie <hr> – brauchen kein schließendes Tag.

Das verbindliche HTML5-Grundgerüst (Klicke auf eine Zeile)

Jede professionelle HTML-Datei beginnt mit demselben Rahmen. Wähle links eine Zeile aus, um ihre Aufgabe im Browser zu untersuchen:

Zeile 1 • Dokumenttyp

<!DOCTYPE html>

Erste Pflichtzeile jeder Datei. Sie teilt dem Browser mit: „Achtung, hier folgt modernes HTML5!“ Ohne sie schaltet der Browser eventuell in einen veralteten Kompatibilitätsmodus.

Wichtig: Es ist eine reine Deklaration – es gibt kein schließendes </!DOCTYPE>.
3 Die wichtigsten Starter-Tags & das Zwiebelprinzip

Für die ersten eigenen Webseiten brauchst du keine 100 Befehle – diese sieben Bausteine reichen für klar strukturierte Texte vollkommen aus:

Tag Englische Herkunft Bedeutung & Einsatz Wichtiger Hinweis
<h1> ... </h1> bis <h6> Heading 1–6 Überschriften in 6 Ebenen (<h1> = Haupttitel, <h2> = Unterkapitel). Nur eine <h1> pro Seite; nicht für „großen Text“ missbrauchen!
<p> ... </p> Paragraph Textabsatz mit automatischem Abstand nach oben und unten. Fließtext immer in <p>-Tags verpacken.
<br> Line Break Erzwingt einen einfachen Zeilenumbruch (ohne neuen Absatz). Leeres Tag (kein End-Tag). Sinnvoll z. B. bei Adressen oder Gedichten.
<hr> Horizontal Rule Zeichnet eine waagerechte Trennlinie zwischen Themenblöcken. Leeres Tag (kein End-Tag).
<strong> ... </strong> Strong Importance Hebt besonders wichtigen Text inhaltlich hervor (meist fett dargestellt). Bedeutet „inhaltlich wichtig“, nicht nur „dicke Schrift“.
<em> ... </em> Emphasis Betont ein Wort oder einen Satzteil (meist kursiv dargestellt). Schachtelung innerhalb von <p> beachten.
<!-- Text --> Comment Notiz im Quelltext für Menschen (z. B. Aufgabenverteilung im Team). Wird vom Browser komplett ignoriert und erscheint nicht auf der Seite.

Typischer Anfängerfehler: Richtig vs. Falsch verschachteln (Zwiebelprinzip)

Tags werden oft ineinander gelegt (z. B. ein <strong> innerhalb eines <p>). Dabei gilt streng das Zwiebelprinzip: Das Tag, das zuletzt geöffnet wurde, muss zuerst wieder geschlossen werden.

Richtig: Saubere Schachtelung (innen vor außen)
<p>Morgen schreiben wir <strong>keinen</strong> Test.</p>

<strong> liegt vollständig innerhalb von <p> ... </p>.

Falsch: Überkreuzte Tags
<p>Morgen schreiben wir <strong>keinen</p></strong>

Hier wurde </p> vor </strong> geschlossen – der Baum bricht auseinander!

5 Verständnis-Check & Merkheft-Sicherung

Überprüfe dein Wissen mit diesen vier typischen Klausur- und Fachgesprächsfragen, bevor du den Merksatz ins Heft oder nach OneNote überträgst.

1 Warum ist HTML keine Programmiersprache wie Python oder Java?
Antwort: HTML ist eine Auszeichnungssprache (Markup Language). Mit HTML formuliert man keine Algorithmen, Bedingungen (if/else), Schleifen oder Berechnungen, sondern beschreibt ausschließlich die Struktur und Bedeutung von Inhalten (Überschrift, Absatz, Trennlinie usw.).
2 Ein Schüler schreibt Text in den <head>. Was passiert im Browser?
Antwort: Der <head> ist für Metadaten gedacht (Zeichensatz, Tab-Titel via <title>, spätere CSS-Verknüpfung). Sichtbarer Inhalt gehört zwingend in den <body>. Steht normaler Text im <head>, gehört er strukturell nicht in die Seite (Browser schieben ihn aus Not manchmal in den Body oder verwerfen das Layout).
3 Warum darf man <h1> nicht einfach nutzen, nur weil ein Satz „schön groß“ aussehen soll?
Antwort: HTML beschreibt die inhaltliche Hierarchie, nicht das Design (dafür ist später CSS zuständig). Suchmaschinen (z. B. Google) und Vorleseprogramme für sehbehinderte Menschen (Screenreader) nutzen <h1> bis <h6> als Inhaltsverzeichnis. Pro Seite gibt es genau eine Hauptüberschrift <h1>.
4 Finde die zwei Fehler in: <p>Heute ist <em>ein guter</p> Tag.</em>
Antwort: Verstoß gegen das Zwiebelprinzip! <em> wurde innerhalb von <p> geöffnet, aber erst nach </p> geschlossen. Korrekt ist:
<p>Heute ist <em>ein guter</em> Tag.</p>
MERKE
HTML-Grundgerüst & erste Struktur-Tags

1. Auszeichnungssprache: HTML (Hypertext Markup Language) beschreibt die logische Struktur einer Webseite mithilfe von Tags (<tag>Inhalt</tag>). Zeilenumbrüche und Mehrfach-Leerzeichen im Quelltext ignoriert der Browser.

2. Das Grundgerüst: Jede HTML-Datei startet mit <!DOCTYPE html> und dem Wurzelelement <html lang="de">. Darin liegen genau zwei Bereiche:

  • <head> (Kopfbereich): Unsichtbare Steuerdaten wie <meta charset="UTF-8"> (für ä, ö, ü, ß) und <title> (Name im Browser-Tab).
  • <body> (Körperbereich): Alles, was im Browserfenster sichtbar angezeigt wird.

3. Zwiebelprinzip & Semantik: Verschachtelte Tags werden von innen nach außen geschlossen. Wähle Tags immer nach ihrer Bedeutung (<h1> einmalig für den Haupttitel, <p> für Absätze, <strong>/<em> für Hervorhebungen) – das optische Design folgt später mit CSS.
