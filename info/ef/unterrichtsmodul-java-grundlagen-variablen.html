Grundlagen von Java & das Variablenkonzept

Wie merkt sich ein Computer Zwischenergebnisse und Namen? Wie kommunizieren Programme über das Konsolen-Terminal mit uns Menschen? Und warum ist das Gleichheitszeichen in einer Programmiersprache fundamental etwas anderes als im Mathematikunterricht? In diesem Modul untersuchen wir die Arbeitsweise des Arbeitsspeichers (RAM), die elementaren Datentypen in Java sowie die fünf goldenen Regeln für sauberen Quelltext.

Begleitendes BlueJ-Projekt Projekt „Grundlagen“ in BlueJ

Zu dieser Lerneinheit gehört die Klasse Grundlagen. Du kannst den Quelltext direkt in BlueJ öffnen und ausprobieren: Rechtsklick auf die Klasse $\to$ new Grundlagen() $\to$ Methoden helloWorld() und unterhaltung() ausführen.

1 Programmierstil: Die 5 Clean-Code-Regeln für Java

Ein Computer akzeptiert Quelltext, solange die Syntax stimmt – egal wie unordentlich er aussieht. In der professionellen Softwareentwicklung schreiben wir Programme jedoch für Menschen, die den Quelltext lesen, verstehen und weiterentwickeln müssen. Im Tafelanschrieb haben wir deshalb fünf verbindliche Grundregeln vereinbart:

• Namenskonventionen in Java
  • Methodennamen immer klein beginnen:
    Aktionen/Verben im lowerCamelCase (z. B. helloWorld(), unterhaltung(), nachRechtsBewegen()).
  • Variablennamen immer klein beginnen:
    Sprechende Nomen im lowerCamelCase (z. B. n, schuelerName, alter, tagesTemperatur).
  • CamelCase-Schreibweise:
    Wortgrenzen werden durch einen Großbuchstaben markiert. Keine Leerzeichen, keine Umlaute (ä, ö, ü) und keine Sonderzeichen!
• Struktur & Lesbarkeit
  • Mit sauberen Einrückungen arbeiten:
    Jeder Codeblock innerhalb geschweifter Klammern { ... } wird um vier Leerzeichen nach rechts eingerückt. So erkennt das Auge sofort die Programmhierarchie.
  • Kommentare sinnvoll nutzen:
    Einzeilige Hinweise mit // erklären schwierige Abschnitte. Schließende Klammern werden zur Orientierung beschriftet (z. B. } // Ende helloWorld).

Der Quelltext aus der Unterrichtsstunde (Grundlagen.java): 

public class Grundlagen 
{
    void helloWorld()
    {
        System.out.print("Hello World");
    } // Ende helloWorld

2 Ausgabe auf der Konsole: System.out.print vs. System.out.println

Wenn wir in BlueJ keinen Zeichenrahmen (wie die Leinwand) verwenden, kommuniziert Java über das Terminal (die Konsole). Es gibt zwei elementare Ausgabe-Befehle:

System.out.print(...)
Gibt den übergebenen Text oder Variablenwert auf der Konsole aus und bleibt in derselben Zeile stehen. Der nächste Ausgabebefehl schreibt direkt hinter dem letzten Zeichen weiter.
System.out.println(...)
(ln = line / new line) Gibt den Text oder Variablenwert aus und springt unmittelbar danach in die nächste Zeile. Der Cursor wartet am Anfang der nächsten Zeile auf neue Ausgaben.
3 Das Variablenkonzept: Das Arbeitsspeicher-Regal

Ein Computer besitzt keinen Notizblock aus Papier, sondern einen flüchtigen Arbeitsspeicher (RAM). Im Tafelanschrieb haben wir den Arbeitsspeicher als Leiter bzw. Hochregal mit vielen nummerierten Fächern modelliert:

  • Jedes Fach besitzt eine eindeutige Speicheradresse (eine Nummer im Speicher).
  • Eine Variable ist ein reserviertes und beschriftetes Fach in diesem Regal.
  • Das Fach hat einen festen Namen (Identifikator), einen Typ (welche Sorte Inhalt hineinpasst) und einen aktuellen Wert.

Um Werte dauerhaft im Arbeitsspeicher abzulegen, sind zwei Dinge zwingend notwendig:
1. Die Deklaration: Dem Computer mitteilen, welchen Typ die Daten haben und wie das Fach heißt.
2. Die Zuweisung: Einen konkreten Wert in das reservierte Fach hineinschreiben.
4 Die 5 elementaren Datentypen in der gymnasialen Einführung

In Java ist jedes Speicherfach typisiert: Man kann in ein Fach für ganze Zahlen keinen Text ablegen. Der Compiler wacht streng darüber, dass Typ und Wert zusammenpassen. Hier sind die fünf Datentypen aus dem Unterricht im Überblick:

Datentyp Java-Schlüsselwort Bedeutung & Inhalt Typisches Beispiel
String String (großgeschrieben!) Zeichenkette (beliebig langer Text). Steht immer in doppelten Anführungszeichen. String n = "Alfred";
Character char Genau ein einzelnes Schriftzeichen. Steht immer in einfachen Hochkommas. char note = 'A';
Integer int Ganze Zahlen (positiv, negativ oder null). Keine Nachkommastellen. int alter = 16;
Double double Dezimalzahlen (Kommazahlen). In Java zwingend mit Punkt statt Komma. double preis = 3.99;
Boolean boolean Wahrheitswerte. Kennt ausschließlich zwei Zustände: true (wahr) oder false (falsch). boolean bestanden = true;
• Warum schreibt man String mit großem „S“, int aber klein?
In Java sind int, double, char und boolean sogenannte primitive Datentypen (Grundbausteine der Sprache, daher kleingeschrieben). String hingegen ist eine vollwertige Klasse (ein komplexer Objekttyp mit eigenen Methoden wie .length()), weshalb er nach den Namenskonventionen großgeschrieben wird. In der EF nutzen wir ihn zunächst wie einen Grundtyp.
5 Code-Anatomie: Deklaration, Zuweisung & Initialisierung

Betrachten wir die zentrale Codezeile aus dem Tafelanschrieb:

String Datentyp
n Variablenname
= Zuweisung
"Alfred" Wert / Literal
; Semikolon

In Java gibt es zwei Wege, eine Variable einsatzbereit zu machen:

Weg A: Zwei Schritte (Getrennt)
String n;          // 1. Deklaration
n = "Alfred";      // 2. Zuweisung

Zuerst wird das Fach im Speicher reserviert (es ist noch leer). Später wird der Wert hineingelegt.

Weg B: Ein Schritt (Initialisierung)
String n = "Alfred";  // Beides zusammen!

Deklaration und erstmalige Zuweisung (Initialisierung) erfolgen direkt in einem Zug. Dies ist der kompaktere und häufigste Programmierstil.

String-Verknüpfung (Konkatenation mit dem Plus-Operator):

In der Methode unterhaltung() steht folgende Zeile: 

System.out.println("Mein Name ist " + n);

Das Pluszeichen + rechnet hier nicht wie in Mathe Zahlen zusammen, sondern klebt Texte aneinander (Konkatenation). Java schaut im Speicherfach n nach, findet dort den Text "Alfred" und fügt ihn nahtlos an den Satzanfang an. Auf der Konsole erscheint: Mein Name ist Alfred.

6 Die Kardinalregel: Bedeutung des Gleichheitszeichens
In der Mathematik ($=$)
In der Mathematik ist $=$ ein Gleichheits- und Relationszeichen (eine Waage).

Aussage: Die linke Seite ist wertgleich zur rechten Seite.
Es gilt Symmetrie: $x = 5$ bedeutet exakt dasselbe wie $5 = x$.
• In Java Informatik ($=$)
In Java ist $=$ kein Gleichheitszeichen, sondern der Zuweisungsoperator!

Aussage: Führe einen aktiven Schreibbefehl von rechts nach links aus ($\leftarrow$).
Der Wert auf der rechten Seite wird in die Variable auf der linken Seite geschrieben.
MERKE
Regeln für den Zuweisungsoperator in Java:
1. Links vom Gleichheitszeichen muss immer der Name eines beschreibbaren Speicherfachs (eine Variable) stehen.
2. Rechts steht der Wert, eine Zahl, ein Text oder eine Berechnung.
3. Der Ausdruck "Alfred" = n; oder 16 = alter; führt zu einem sofortigen Compiler-Fehler, weil man einem festen Wert nichts zuweisen kann!

8 Merkheftsicherung: Zusammenfassung für das Heft
Hefteintrag Übertrag in das Informatik-Heft

Übertrage den folgenden Merkkasten und die Übersicht der Datentypen sauber in dein Heft. Achte besonders auf die Kennzeichnung von Deklaration und Zuweisung.

MERKE

1. Das Variablenkonzept

Eine Variable ist ein beschrifteter Platzhalter im Arbeitsspeicher (RAM).
• Deklaration: Reserviert das Fach unter Angabe von Datentyp und Bezeichner (z. B. String n;).
• Zuweisung: Speichert einen Wert im reservierten Fach (z. B. n = "Alfred";).
• Initialisierung: Deklaration und erstmalige Zuweisung in einer einzigen Zeile (String n = "Alfred";).

2. Der Zuweisungsoperator ($=$)

Das Zeichen = ist in Java keine Gleichheitswaage wie in der Mathematik, sondern ein Zuweisungsbefehl von rechts nach links ($\leftarrow$).
Der Wert der rechten Seite wird in die Variable der linken Seite geschrieben.

3. Konsole & Datentypen

• System.out.print(...) bleibt in derselben Zeile.
• System.out.println(...) setzt nach der Ausgabe einen Zeilenumbruch.
• Die fünf Grundtypen: String (Text in "..."), char (Zeichen in '...'), int (Ganze Zahl), double (Dezimalzahl mit Punkt), boolean (true / false).
