Rechnen mit Variablen & die Selbstzuweisung

Variablen heißen nicht ohne Grund Variablen: Ihr Inhalt ist veränderlich (variabel). Bisher haben wir Werte lediglich deklariert und starr auf der Konsole ausgegeben. In dieser Lerneinheit machen wir den Computer zur echten Rechenmaschine: Wir lernen die Grundoperatoren kennen, untersuchen die tückische Ganzzahldivision, berechnen Divisionsreste mit dem Modulo-Operator und lüften das Geheimnis der Selbstzuweisung punkte = punkte + 5;.

Zentrales Lernziel Vom Speicherfach zum Rechenprozess

Nach dieser Einheit kannst du: (1) Die fünf Grundoperatoren in Java sicher anwenden, (2) den Unterschied zwischen int- und double-Division erklären, (3) mit dem Modulo-Operator % rechnen und (4) Schritt für Schritt nachvollziehen, was bei Selbstzuweisungen wie x = x + 1; im Arbeitsspeicher geschieht.

1 Die vier Grundrechenarten in Java

In Java können Zahlenwerte direkt oder über ihre Variablennamen miteinander verrechnet werden. Die Rechenregeln entsprechen denen der Schulmathematik: Punktrechnung (*, /) geht vor Strichrechnung (+, -), und Klammern ( ... ) haben stets Vorrang.

Rechenart Operator Java-Codebeispiel Ergebnis im RAM
Addition + int summe = 15 + 4; Wert 19
Subtraktion - int rest = 20 - 7; Wert 13
Multiplikation * int flaeche = 6 * 8; Wert 48 (Sternchen statt $\cdot$)
Division / double halbe = 10.0 / 4.0; Wert 2.5 (Schrägstrich statt :)
Regel Rechnen mit bestehenden Variablen

Man muss keine festen Zahlen hinschreiben. Es können beliebige Variablen eingesetzt werden: 

int laenge = 10;
int breite = 4;
int umfang = 2 * (laenge + breite);  // Ergibt 28
System.out.println("Umfang: " + umfang);
2 Die Division: Der große Unterschied zwischen int und double

Bei der Division lauert in Java der häufigste Rechenfehler von Programmieranfängern: Die sogenannte Ganzzahldivision.

• Fall A: Die int-Ganzzahldivision
Wenn zwei ganze Zahlen (int) geteilt werden, ist das Ergebnis für Java zwingend wieder ein int!

Alle Nachkommastellen werden einfach abgeschnitten (nicht gerundet!).

int ergebnis = 7 / 2; $\to$ Ergebnis: 3 (nicht 3.5!).
int test = 1 / 2; $\to$ Ergebnis: 0 (nicht 0.5!).
• Fall B: Die echte Fließkommadivision
Sobald mindestens ein Operand eine Dezimalzahl (double) ist, rechnet Java mit Nachkommastellen weiter:

double ergebnis = 7.0 / 2; $\to$ Ergebnis: 3.5.
double test = 1.0 / 2; $\to$ Ergebnis: 0.5.

Tipp: Wenn man zwei int-Variablen teilt, kann man einen Operanden mit 1.0 * a / b zu double befördern.
• Warum ergibt double x = 7 / 2; in Java überraschend 3.0 und nicht 3.5?
Das ist die klassische Anfängerfalle! Java wertet zuerst die rechte Seite aus: Dort steht 7 / 2. Weil beides int-Zahlen sind, führt Java eine Ganzzahldivision durch und erhält 3. Erst danach wird die Zuweisung an die linke Seite (double x) ausgeführt. Die Zahl 3 wird zu 3.0 umgewandelt. Die Nachkommastelle .5 war da bereits unwiderruflich verloren! Lösung: double x = 7.0 / 2; schreiben.
3 Der Modulo-Operator (%): Rechnen mit dem Divisionsrest

In der Grundschule hat man geteilt, bevor man Brüche kannte: „14 geteilt durch 4 ist 3, Rest 2.“ Genau diesen Rest liefert in Java das Prozentzeichen %, genannt Modulo-Operator:

MERKE
Der Modulo-Operator (%) berechnet den ganzzahligen Rest einer Division:
• 14 / 4 ergibt 3 (Wie oft passt die 4 ganz hinein?)
• 14 % 4 ergibt 2 (Welcher Rest bleibt übrig?)

Warum ist Modulo in der Informatik so wichtig?

• 1. Gerade oder ungerade Zahl?
Jede gerade Zahl lässt sich ohne Rest durch 2 teilen. Teilt man eine Zahl durch 2 mit Modulo, bleibt entweder 0 oder 1 übrig:
• 8 % 2 $\to$ 0 (gerade Zahl)
• 9 % 2 $\to$ 1 (ungerade Zahl)
• 2. Zeit- & Einheitenrechnung
Wie viele Minuten und Restsekunden sind 125 Sekunden?
• Minuten: 125 / 60 $\to$ 2 Minuten
• Restsekunden: 125 % 60 $\to$ 5 Sekunden
Ergebnis: 2 Minuten und 5 Sekunden!
4 Die Selbstzuweisung: punkte = punkte + 5;

Stell dir vor, du programmierst ein Spiel. Ein Spieler sammelt eine Münze ein und erhält 5 Punkte dazu. Im Quelltext steht: 

int punkte = 10;
punkte = punkte + 5;
Aus Sicht der Mathematik
Gleichung: $x = x + 5$
Zieht man auf beiden Seiten $x$ ab, erhält man:
$0 = 5 \implies$ Widerspruch / Unlösbar!
Keine Zahl der Welt kann gleich sich selbst plus 5 sein.
• Aus Sicht von Java (Arbeitsspeicher)
Es ist keine Gleichung, sondern ein Zuweisungsbefehl!
Java arbeitet strikt von rechts nach links ($\leftarrow$):
1. Lies den alten Wert aus dem Fach punkte aus (10).
2. Rechne 5 dazu: $10 + 5 = 15$.
3. Schreibe das Ergebnis 15 in das Fach punkte zurück.

Schritt-für-Schritt im Arbeitsspeicher:

1
Rechte Seite auswerten: Java schaut im Speicherfach punkte nach. Dort liegt aktuell der Wert 10.
2
Rechnung ausführen: Java berechnet den Gesamtwert der rechten Seite: 10 + 5 = 15.
3
Zuweisung durchführen: Der alte Wert 10 wird im Speicherfach punkte überschrieben. Das Fach enthält ab sofort den neuen Wert 15.
5 Kurzschreibweisen & der Inkrement-Operator

Weil Selbstzuweisungen wie das Erhöhen eines Punktestands ständig vorkommen, haben die Erfinder von Java praktische Kurzschreibweisen eingebaut:

Ausführliche Schreibweise Verkürzte Schreibweise Bedeutung
punkte = punkte + 5; punkte += 5; Erhöht punkte um 5.
leben = leben - 1; leben -= 1; Verringert leben um 1.
faktor = faktor * 2; faktor *= 2; Verdoppelt den Wert der Variable.
x = x + 1; x++; Inkrement: Erhöht die Variable genau um 1.
x = x - 1; x--; Dekrement: Verringert die Variable genau um 1.
Informatik-Wissen Warum heißt die Programmiersprache C++ eigentlich C++?

Die Programmiersprache C war der berühmte Vorgänger von C++ und Java. Der Erfinder Bjarne Stroustrup wollte ausdrücken, dass seine neue Sprache „C um einen Schritt weiterentwickelt“ ist. Daher nannte er sie mit dem Inkrement-Operator C++!

6 Praxis-Code: Die Klasse Rechner

Hier ist eine vollständige Java-Klasse, die alle Rechenarten demonstriert. Du kannst sie in BlueJ ausprobieren: 

public class Rechner 
{
    // Demonstriert Grundrechenarten & Ganzzahldivision
    void grundrechenarten()
    {
        int a = 17;
        int b = 4;
        
        System.out.println("Addition: " + (a + b));        // 21
        System.out.println("Ganzzahldivision: " + (a / b)); // 4
        System.out.println("Modulo (Rest): " + (a % b));    // 1 (denn 4*4 + 1 = 17)
    }
    
    // Demonstriert die Selbstzuweisung bei einem Punktestand
    void spielStand()
    {
        int punkte = 0;
        System.out.println("Start: " + punkte);  // 0
        
        punkte = punkte + 10;                     // Münze eingesammelt
        punkte += 50;                             // Bonus geholt
        punkte++;                                 // Einzelschritt
        
        System.out.println("Endstand: " + punkte); // 61
    }
    
    // Rechnet Sekunden in Minuten und Rest-Sekunden um
    void zeitUmrechnen()
    {
        int gesamtSekunden = 145;
        int minuten = gesamtSekunden / 60;
        int restSekunden = gesamtSekunden % 60;
        
        System.out.println(gesamtSekunden + " s sind " + minuten + " min und " + restSekunden + " s.");
    }
} // Ende Klasse

Übertrage den folgenden Merkkasten sauber in dein Heft. Achte besonders auf den Modulo-Operator und das Prinzip der Selbstzuweisung.

MERKE

1. Arithmetik & Division in Java

• Operatoren: + (Addition), - (Subtraktion), * (Multiplikation), / (Division).
• Ganzzahldivision: Teilen zweier int-Zahlen schneidet Nachkommastellen ab (7 / 2 ergibt 3). Für Dezimalergebnisse muss mindestens ein Operand double sein (7.0 / 2 ergibt 3.5).
• Modulo (%): Berechnet den ganzzahligen Divisionsrest (14 % 4 ergibt 2).

2. Die Selbstzuweisung & Inkrement

• x = x + 5; liest den alten Wert von x, rechnet 5 dazu und speichert das Ergebnis zurück in x.
• Kurzschreibweisen: x += 5;, x -= 3;, x *= 2;.
• Inkrement (x++;) erhöht um 1, Dekrement (x--;) verringert um 1.
